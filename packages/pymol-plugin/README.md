# AtomWorks Studio for PyMOL

Native Qt panels for loading, annotating, and saving molecular structures.
The plugin uses Studio's shared editing library without a web server.

## Setup

Install in the Python environment that runs PyMOL. See the
[installation guide](../../docs/INSTALLATION.md) for source and wheel installs,
and the [PyMOL guide](../../docs/PYMOL.md) for installation, native panel workflows,
console commands, and updating an existing installation.
